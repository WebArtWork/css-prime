# css-prime Headless

`@wawjs/css-prime-headless` provides experimental framework-neutral headless utilities.

```bash
pnpm add @wawjs/css-prime-headless@0.1.0
```

This package is experimental and starts at `0.1.0`. css-prime is an independent
MIT-licensed continuation of the PrimeUIX `0.7.0` codebase, maintained by Web Art Work.
See the repository [NOTICE](https://github.com/WebArtWork/css-prime/blob/master/NOTICE.md).
